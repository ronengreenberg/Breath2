# סוכן הזדמנויות

סורק שוק שמחפש הזדמנויות ומדרג אותן. הוא רק מוצא ומדווח, ולא מבצע עסקאות.

## מה הוא סורק

| סורק | מה הוא מחפש | מקור נתונים |
|---|---|---|
| `crypto` | אותו מטבע במחיר שונה בין Binance, OKX, Bybit, KuCoin ו-Gate, אחרי עמלות | APIs ציבוריים |
| `triangular` | מחזור USDT → A → B → USDT בבינאנס שמסתיים ברווח | Binance |
| `funding` | Funding rate גבוה בחוזים עתידיים: קונים ספוט ושורטים את החוזה (delta-neutral) | Binance, Bybit |
| `mergers` | פער בין מחיר המניה למחיר העסקה במיזוגים שהוכרזו (מתוך `deals.json`) | Yahoo Finance |
| `stocks` | מכירת יתר בתוך מגמת עלייה, פריצה עם מחזור חריג, קרבה לשפל שנתי | Yahoo Finance |

## הרצה

```bash
pip install -r requirements.txt
python agent.py                      # סריקה אחת
python agent.py --only crypto funding
python agent.py --loop 15            # סריקה כל 15 דקות
python agent.py --ai                 # מוסיף סיכום בעברית מ-Claude (צריך ANTHROPIC_API_KEY)
```

הדו"חות נשמרים בתיקייה `reports/` כקובצי Markdown ו-JSON.

**התראות בטלגרם:** מגדירים את `TELEGRAM_BOT_TOKEN` ואת `TELEGRAM_CHAT_ID`. הסוכן ישלח הודעה כשהוא מוצא הזדמנות ארביטראז'.

## התאמה אישית

- `config.json`: רשימת המטבעות והמניות, עמלות לכל בורסה (עדכן לפי דרגת העמלה שלך) והספים.
- `deals.json`: מכניסים עסקאות מיזוג שהוכרזו: מחיר במזומן למניה, ו/או כמה מניות של הרוכש מקבלים על כל מניה, ותאריך סגירה צפוי.

## חשוב לדעת

- זה לא ייעוץ השקעות. כל מספר הוא תמונת מצב רגעית.
- **פער גדול בין בורסות הוא בדרך כלל לא כסף חינם.** לרוב ההפקדות או המשיכות של המטבע חסומות, או שמדובר בטוקן אחר עם אותו שם. הסוכן מסמן פערים מעל 5% כחשודים.
- עמלות משיכה, זמן העברה, עומק ספר הפקודות ומסים לא נכללים בחישוב.
- ארביטראז' משולש בבורסה גדולה כמעט תמיד נסגר בתוך מילישניות על ידי בוטים מהירים.
- ב-Funding carry ההכנסה משתנה בכל תקופת מימון, והשורט על החוזה עלול להיחסל בקפיצה חדה אם אין מספיק בטחונות.
- הסיגנלים על מניות הם רשימת מועמדים לבדיקה, לא המלצת קנייה.
